# TORQ (TORQai) 

**Every Rig. Every Deal. One Signal.**

TORQ is an AI-powered vehicle sourcing platform and unified marketplace aggregator for independent auto dealers. It combines the original vision of aggregating private seller and dealer listings (from eBay, Facebook Marketplace, Craigslist, etc.) with a high-end autonomous AI agent workflow that automatically sources, scores, and presents the best deals to dealers.

## Overview

The platform uses a Dark Luxury Next.js Dashboard to provide dealers with a "Human Approval Gate." When a dealer submits an inventory request, the autonomous backend (OpenClaw + Next.js API):
1. Aggregates live listings from **Auto.dev** (and eventually Marketcheck/Custom Scrapers).
2. Enriches the listings via the **NHTSA vPIC API** for recalls, damage context, and VIN decoding.
3. Ranks each vehicle from 0-100 based on the **TORQ Deal Scoring Algorithm** (Price, Mileage, Condition, Proximity).
4. Drafts FTC-compliant outbound communications (Twilio SMS/WhatsApp, Resend Email).
5. Halts and waits for the dealer to review and "Approve" via the dashboard before dispatching the messages.

## Deal Scoring Algorithm

Vehicles are scored out of 100 based on their alignment with market averages and the dealer's specific intake request:
- **Price Fit (30%)**: Punishes listings above the target max price.
- **Mileage (25%)**: Rewards vehicles with significantly lower mileage (< 50k miles = max points).
- **Condition (25%)**: Penalizes minor or severe damage statuses derived from NMVTIS or proxy logic.
- **Proximity (20%)**: Distance logic based on seller zip code relative to the dealer.

*Note: The algorithm is designed to transition seamlessly from static API queries to tracking market averages generated by our custom scrapers.*

## Setup & Local Development

1. **Clone the Repository**
2. **Install Dependencies**
   ```bash
   cd dashboard
   npm install
   ```
3. **Configure Environment Variables**
   Create a `.env.local` inside `dashboard/`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
   AUTODEV_API_KEY=your_auto_dev_api_key
   ```
   *Note: If `AUTODEV_API_KEY` is omitted, the app will gracefully fall back to generating realistic mock data for UI testing.*
4. **Initialize Database**
   Run the `db/schema.sql` commands in your Supabase SQL editor.
5. **Run the Dashboard**
   ```bash
   npm run dev
   ```
